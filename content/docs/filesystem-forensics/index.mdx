---
title: Filesystem Forensics
description: Learn volume structures and filesystem structures as related but distinct forensic layers.
---

This section keeps two layers distinct:

1. **Volume Analysis** examines structures that divide or assemble storage into volumes, such as MBR and GPT.
2. **File System Analysis** examines structures inside a filesystem that organize content, metadata, names, allocation, and application-level features.

For navigation they live under one learning section, but an MBR partition entry is not an NTFS structure.

~~~text
evidence image
  ↓
volume / partition structure
  ↓
partition start
  ↓
filesystem boot sector
  ↓
filesystem metadata
  ↓
file records
  ↓
attributes and content
~~~

Each transition changes the address space and the structure definition that applies.
