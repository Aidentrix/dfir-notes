---
title: File System Analysis
description: Examine structures a filesystem uses to organize content, metadata, names, and allocation.
---

File system analysis begins after the examiner has established where the filesystem lives.

Carrier separates filesystem data into five categories:

1. File System Category
2. Content Category
3. Metadata Category
4. File Name Category
5. Application Category

The model helps identify which class of structure should contain the information being sought and which validation technique makes sense.
