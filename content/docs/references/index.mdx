## Reference discipline

~~~text
documented structure -> how a field is interpreted
observed bytes       -> what the evidence actually contains
tool output          -> one parser's interpretation
validation           -> comparison with an independent observation
~~~

When offsets are published, the page names the base address space so image-absolute, volume-relative, record-relative, and attribute-relative coordinates are not conflated.
