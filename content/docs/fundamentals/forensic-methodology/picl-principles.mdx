---
title: PICL Principles
description: Carrier's preservation, isolation, correlation, and logging guidelines.
---

Carrier uses **PICL** as a compact set of forensic-procedure guidelines:

| Principle | Examiner focus |
| --- | --- |
| Preservation | Minimize avoidable changes and retain recoverable originals or copies. |
| Isolation | Keep suspect data and risky execution separated from the analysis environment and outside systems. |
| Correlation | Support important findings with independent sources or observations when practical. |
| Logging | Record actions, searches, commands, results, and procedural decisions. |

PICL does not replace organizational legal, laboratory, or chain-of-custody requirements. It is a technical discipline for performing and documenting analysis without making the tool itself the authority.
